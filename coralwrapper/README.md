# coralwrapper

`coralwrapper` is a Chipyard-style wrapper around CoralNPU that lets you emit
single-file Verilog plus FIRRTL from named configs using:

```bash
make CONFIG=CoralNPUConfig
```

## Repository layout

- `coralnpu/` is a Git submodule pointing to the CoralNPU repository.
- `external/*` are Git submodules used by CoralNPU Chisel BlackBox resources:
  - `external/common_cells`
  - `external/cvfpu`
  - `external/fpu_div_sqrt_mvp`
  - `external/RVVI`

## Setup

```bash
git submodule update --init --recursive
```

## Build

Default:

```bash
make
```

Equivalent explicit:

```bash
make CONFIG=CoralNPUConfig
```

Print resolved args for a config:

```bash
make print-config CONFIG=CoralNPUConfig
```

Build output:

- `build/verilog/<CONFIG>/`

Primary artifacts:

- `<ModuleName>.sv` (single SystemVerilog file)
- `<ModuleName>.fir` (FIRRTL/CHIRRTL intermediate)
- `V<ModuleName>_parameters.h` (if generated by emitter)
- `generated.sv` and `generated.fir` convenience copies

## Chipyard generator integration

This wrapper is structured so it can live under:

```bash
<chipyard>/generators/coralwrapper
```

Then you can run from Chipyard root:

```bash
cd generators/coralwrapper
make CONFIG=CoralNPUConfig
```

The wrapper does not require Bazel; it drives Chisel emission through SBT and
named configs in Chipyard style (`CONFIG=<Name>`).

## Configs

The wrapper currently supports all existing CoralNPU core-emission configs:

- `CoralNPUConfig` -> `RvvCoreMiniVerificationAxi.sv`
- `CoreConfig` -> `Core.sv`
- `CoreScalarConfig` -> `CoreScalar.sv`
- `CoreMiniConfig` -> `CoreMini.sv`
- `CoreMiniAxiConfig` -> `CoreMiniAxi.sv`
- `CoreMiniVerificationAxiConfig` -> `CoreMiniVerificationAxi.sv`
- `CoreMiniHighmemAxiConfig` -> `CoreMiniHighmemAxi.sv`
- `CoreMiniITCM512DTCM512AxiConfig` -> `CoreMini_ITCM512KB_DTCM512KBAxi.sv`
- `RvvCoreMiniTlulConfig` -> `RvvCoreMiniTlul.sv`
- `RvvCoreMiniAxiConfig` -> `RvvCoreMiniAxi.sv`
- `RvvCoreMiniVerificationAxiConfig` -> `RvvCoreMiniVerificationAxi.sv`
- `RvvCoreMiniHighmemAxiConfig` -> `RvvCoreMiniHighmemAxi.sv`
- `RvvCoreMiniITCM512DTCM512AxiConfig` -> `RvvCoreMini_ITCM512KB_DTCM512KBAxi.sv`
